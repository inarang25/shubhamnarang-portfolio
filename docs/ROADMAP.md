# shubhamnarang.in — roadmap

Working notes for growing this site from a portfolio into a full personal home (a "digital twin"): ideas, projects, writing, images, all in one place.

## Where it is now

One site, one menu on every page: **Work · Writing · About**.

| URL | File | What it is |
|---|---|---|
| `/` | `index.html` | Home: short intro, impact figures, then projects by category. |
| `/work/processpro` | `work/processpro.html` | ProcessPro case study. New case studies go in `work/`. |
| `/writing` | `writing.html` | Blog index (empty for now). Posts will live at `/writing/<slug>`. |
| `/about` | `about.html` | Pop-art page: background, career, education, skills, certifications. `/builder` redirects here. |
| anything else | `404.html` | Not-found page. |

### Home page structure

1. **Intro** — who I am in one sentence, one line of background.
2. **Impact** — four figures (250+ KPIs, 15% at IBM, ₹50 Cr and 10% cost cut at L&T).
3. **01 Products** — ProcessPro (flagship, links to its case study), nurchur.in.
4. **02 Enterprise transformation** — Project Vihan, demand.ai (pilot), IBM, L&T.
5. **03 Analytics studies** — dashboard studies.
6. **04 Data science & experiments** — models, tests, process mining.
7. **Writing** teaser, then contact footer.

### Design

- Minimal: white ground, near-black text, grey secondary text, hairline rules; follows the visitor's light/dark setting.
- Type: Geist, with Geist Mono for small labels.
- Shared styles in `assets/site.css`. `index.html`, `writing.html`, `work/processpro.html` and `404.html` are generated by `tools/build_site.py` (`python3 tools/build_site.py .`) so the header and footer stay identical; edit content there.
- The About page keeps its own pop-art styling and is edited directly.
- Rules for ProcessPro: say the company is fictional and data synthetic; money before GST; no employer named; private repo not linked. demand.ai is a pilot, so no accuracy figure.

## The bigger picture: a personal twin

Sections the site can grow into, each a page of its own:

| Section | What goes there |
|---|---|
| `/work/<project>` | A full case study per project (problem → approach → outcome, screenshots, live dashboards). |
| `/lab` | Capstones and experiments, each with a short write-up as it matures. |
| `/writing` | Essays and longer posts. RSS feed. |
| `/ideas` | Short notes and half-formed thoughts — a "digital garden" that's allowed to be unfinished. |
| `/gallery` | Photos, sketches, images. |
| `/now` | A dated "what I'm doing now" page. |
| `/ask` | **The twin itself**: a chat that answers questions about my work and thinking, grounded only in what's published on this site, and says so when it doesn't know. |

Examples researched: digital gardens (personal wikis where notes grow over time) and "AI twin" portfolios such as Twinfolio — open-source, answers from your own work and admits gaps.

## Suggested order

1. ✅ Restructure the main page and give it its own minimal identity.
2. Move to **Astro** (a static-site tool built for content sites, first-class on Vercel). One content folder feeds every page, so nothing is written twice; posts and notes become simple Markdown files.
3. Add `/writing` and `/ideas`, then project pages under `/work`.
4. Add `/gallery` and `/now`.
5. Build `/ask` — a small serverless function on Vercel that calls an LLM with the site's own content as its only source.
